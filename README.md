📘 Descrição do Projeto

Com o objetivo de modernizar sua infraestrutura e atender requisitos de segurança e escalabilidade, a Abstergo Industries está migrando 
parte de seus sistemas para a nuvem AWS. 

O projeto foi estruturado em três etapas principais:

🧹 Etapa 1: Armazenamento Seguro de Dados

Serviço AWS: Amazon S3
Objetivo: Armazenar dados clínicos e documentos regulatórios de forma escalável e segura.
Benefícios: Versionamento, criptografia automática, conformidade com LGPD e FDA.

⚙️ Etapa 2: Processamento Automatizado de Dados
Serviço AWS: AWS Lambda
Objetivo: Automatizar o processamento de dados laboratoriais e relatórios.
Benefícios: Redução de custos com servidores e resposta em tempo real.

🔒 Etapa 3: Auditoria e Conformidade
Serviço AWS: AWS CloudTrail
Objetivo: Rastrear ações e garantir conformidade regulatória com logs detalhados.
Benefícios: Transparência, segurança e suporte a auditorias internas e externas.
